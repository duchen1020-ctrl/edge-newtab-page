如何安装「美化主页 - 新标签页」扩展（Chrome / Edge / Firefox）
==========================================================

1. 打开浏览器扩展管理页
   - Chrome：地址栏输入   chrome://extensions
   - Edge：  地址栏输入   edge://extensions
   - Firefox：地址栏输入  about:debugging#/runtime/this-firefox
2. 打开右上角的「开发者模式」(Developer mode) 开关
   （Firefox 点「临时载入附加组件」→ 选择 newtab-extension 里的 manifest.json）
3. 点击「加载已解压的扩展程序」(Load unpacked)
4. 选择本文件夹（newtab-extension）
5. 完成后，按 Ctrl+T 打开任意新标签页，即可看到美化主页

使用说明
--------
- 本扩展用「内嵌副本」覆盖新标签页，搜索框、快捷链接、暗化/模糊、动态壁纸轮换、
  天气卡片、玻璃效果调节 全部可用。
- 出于浏览器安全限制，扩展与本地主文件（index.html）的数据相互隔离、互不可见。
  首次使用时，请在右上角 ⚙ 里重新设置一次壁纸（重选「文件夹」或上传图片/视频即可），
  设置会保存在扩展自身，之后每一个新标签页都会自动生效。
- 想卸载：在扩展管理页找到本扩展，点「移除」即可，不影响原来的 index.html。
- 修改扩展文件后，必须回到扩展管理页点「刷新」重新加载，否则改动不生效。

天气卡片（左下角）
-----------------
- 自动定位所在城市并显示实时天气、温度、今日高低温、未来 3 天预报。
- 卡片内含动态粒子特效：晴天旋转光束 / 多云飘动云雾 / 下雨落雨滴 / 下雪飘雪花 / 有雾流动雾带，
  鼠标悬停时粒子加速，卡片会有跟随鼠标的柔光高光。
- 搜索城市：输入框内输入城市名（如「上海」），下拉选择即可切换；📍 重新定位，↻ 刷新数据。
- 数据源为 Open-Meteo 公开接口（免费、无需密钥），首次使用需联网。
- 想让卡片更透明/更模糊：右上角 ⚙ →「卡片玻璃效果」→ 调整「淡化」「模糊」「天气」三个滑块。

音乐窗口 · 在线解析（B站 / 网易云）
-----------------------------------
- 点右下角 🎵 打开音乐窗口，下方「在线解析」区：粘贴链接即可解析播放。
- **哔哩哔哩**：粘贴视频链接、av 号或 BV 号（如 BV1GJ411x7h7），自动提取最高音质音频，
  并显示视频封面与标题。
- **网易云**：粘贴歌曲分享链接或歌曲 ID，可选音质（标准/极高/无损/Hi-Res/超清母带），
  解析后自动显示同步滚动歌词。
- 原理：扩展后台 service worker（background.js）直连各平台官方接口，
  绕过浏览器跨域(CORS)限制；音频文件本身开放 CORS，故频谱可正常显示。
- 歌词：优先从网易云获取；若网易云因版权/登录限制未返回歌词，会自动到酷狗歌词库
  按「歌名 + 时长」兜底检索，绝大多数歌曲可拿到同步滚动歌词。
- B站视频通常没有内嵌歌词，此时会提示「可手动粘贴 LRC」。
- 该功能依赖后台脚本，每次修改本扩展文件后，请回到扩展管理页点「刷新」重新加载，
  否则可能出现「解析失败：请确认扩展已重新加载」。

index.html 版（不用装扩展时）
--------------------------
- 直接双击 index.html 即可使用主页。
- 但 B站/网易云解析受浏览器跨域限制，需先双击 start-proxy.bat 启动本地代理
  （窗口保持开启，关闭即停止服务）。
- 若 start-proxy.bat 窗口出现乱码或报错，请确认已安装 Node.js LTS。

进阶（可选，推荐长期使用）
--------------------------
如果你已经把 index.html 发布成一个网页（拿到 http 开头的网址），
可以改为「重定向模式」，让所有新标签页直接打开同一份主页，数据完全共享：
把 newtab.html 的内容整文件替换为下面这一行即可（把网址换成你的主页地址）：

    <script>window.location.href = "你的主页网址";</script>
