如何安装「美化主页 - 新标签页」扩展（Chrome / Edge）
=================================================

1. 打开浏览器扩展管理页
   - Chrome：地址栏输入   chrome://extensions
   - Edge：  地址栏输入   edge://extensions
2. 打开右上角的「开发者模式」(Developer mode) 开关
3. 点击「加载已解压的扩展程序」(Load unpacked)
4. 选择本文件夹（newtab-extension）
5. 完成后，按 Ctrl+T 打开任意新标签页，即可看到美化主页

使用说明
--------
- 本扩展用「内嵌副本」覆盖新标签页，搜索框、快捷链接、暗化/模糊、动态壁纸轮换
  全部可用，且完全离线、不依赖网络。
- 出于浏览器安全限制，扩展与本地主文件（index.html）的数据相互隔离、互不可见。
  首次使用时，请在右上角 ⚙ 里重新设置一次壁纸（重选「文件夹」或上传图片/视频即可），
  设置会保存在扩展自身，之后每一个新标签页都会自动生效。
- 想卸载：在扩展管理页找到本扩展，点「移除」即可，不影响原来的 index.html。

音乐窗口 · 网易云解析
---------------------
- 点右下角 🎵 打开音乐窗口，下方有「网易云音乐」区：粘贴网易云歌曲链接或歌曲 ID，
  选好音质后点「解析」即可直接播放，并实时显示频谱柱形图。
- 原理：扩展后台 service worker（background.js）代发请求到第三方解析接口
  tools.qzxdp.cn，绕过浏览器跨域(CORS)限制；音频文件本身开放 CORS，故频谱可正常显示。
- 该功能依赖后台脚本，每次修改本扩展文件后，请回到扩展管理页点「刷新」重新加载，
  否则可能出现「解析失败：请确认扩展已重新加载」。

进阶（可选，推荐长期使用）
--------------------------
如果你已经把 index.html 发布成一个网页（拿到 http 开头的网址），
可以改为「重定向模式」，让所有新标签页直接打开同一份主页，数据完全共享：
把 newtab.html 的内容整文件替换为下面这一行即可（把网址换成你的主页地址）：

    <script>window.location.href = "你的主页网址";</script>
